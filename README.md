GoCal
Calorie Tracking Web Application
Project Status: Ongoing
Problem Statement: Many Fitnesss Enthusiasts,Atheletes and Fitness influencers struggle to track their daily calorie intake and macronutrient balance due to lack of awareness and overly existing tools, resulting in inconsistent progress toward fitness goals
GoCal is a smart calorie tracking web application aimed at helping users monitor daily nutrition, track macronutrients, manage personalized fitness goals. 
Building a real time calorie and macronutrient calculation system based on user data (age, weight, goals, activity level) alongside implementing an interactive data visualization(Pier Chart, Graphs) for macro breakdown using charting libraries and developing multiple features in progress like calorie goal tracking, intake analysis, and calorie insights for better decision-making with the help of an AI chatbot and AI review system. 
Tech Stack:
       Frontend: React.js, JavaScript, CSS
       State Management: React Context API
       Authentication: Firebase Authentication
       Data Storage: LocalStorage
       Visualization: Recharts
       AI: Hugging Face API key, ChatGPT 5.1
       Development Tool: Visual Studio Code
