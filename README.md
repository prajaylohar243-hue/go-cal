Project Status: Ongoing
Problem Statement: Many individuals struggle to consistently track their daily calorie intake and nutrient balance due to lack of awareness and overly complex tools, resulting in inconsistent progress toward fitness goals.
GoCal is a smart calorie tracking web application aimed at helping users monitor daily nutrition, track calories intake and burnout, manage personalized fitness goals. 
Architected real-time calorie and nutrient calculation system based on user data (age, weight, goals, activity level) with interactive data visualization(Pie Chart, Graphs) for macro breakdown using charting libraries and implementing multiple features like calorie goal tracking, intake analysis, calorie insights, food logging, daily intake tracking, and goal-based calorie estimation.
Tech Stack:
       Frontend: React.js, JavaScript, CSS
       State Management: React Context API
       Data Storage: LocalStorage
       Visualization: Recharts
       Development Tool: Visual Studio Code
